# 🧪 Solution-Preparation Workstation Manual (Draft v1, EN)

## 1. Solution-Preparation Workstation: Overview and Capabilities

The Solution-Preparation workstation is the **primary liquid-handling entry point** in the robotic synthesis workflow.
It is responsible for adding pre-prepared reagent solutions into tubes according to a specified ratio table.

**Critical rule: the robot can only handle liquids, never solids.**
All solid reagents must be **manually dissolved into solutions** before the experiment and placed in the reagent bottles assigned to this workstation.

---

## 2. Solution-Preparation Arguments: Required Input ratio_table Parameter

The main input to this workstation is:

```
parameters:
ratio_table: <string>          # path to a ratio_generator-produced CSV
mixing_time_min: <integer>
tube_cap_state: <"open" | "closed">
```

### 2.1 The ratio_table must be produced by ratio_generator

* Only CSV files generated by **ratio_generator** are accepted.
* The CSV contains per-tube dosing instructions (mL of each solution).
* The robot executes the table exactly and does not infer missing values.

### 2.2 One Solution-Preparation step = one ratio_table

Each Solution-Preparation step corresponds to **one and only one** ratio_table.

If your workflow requires multiple independent ratio sets, you must insert **multiple Solution-Preparation steps**.

### **2.3 Consecutive liquid-addition operations should be merged**

If the experiment conceptually involves *several liquid additions in sequence*,
**you do NOT need to create multiple consecutive Solution-Preparation steps.**

Instead:

* Simply **combine all required volumes into a single ratio_table**,
* And execute them in **one** Solution-Preparation step.

This reduces workflow complexity and avoids unnecessary splitting of steps.

Multiple Solution-Preparation steps should only be used when:

* Different cap states are required between additions, or
* A later step (e.g., ultrasonic-treatment or centrifuge-purification) must occur between additions.

---

## 3. Solution-Preparation Capabilities: Tube Cap State Management and Control

The workstation has a fully automated cap-opening and cap-closing mechanism.
At the start of every experiment, all tubes are **initially uncapped (open)**.

Different downstream workstations may impose strict cap requirements:

* **Centrifuge-purification:** requires closed tubes
* **Ultrasonic-treatment:** requires open tubes
* **Oven-station:** requires closed tubes

Therefore every Solution-Preparation step must explicitly specify:

```
tube_cap_state: "open" or "closed"
```

This makes Solution-Preparation the **cap-state control node** of the entire workflow.

---

## 4. Solution-Preparation Constraints: Volume Limits and Safety Requirements

All tubes used are **50 mL conical tubes**, but for safety and headspace reasons:

### **The total liquid volume in each tube must not exceed 25 mL.**

Before execution, the workstation will:

* Compute the total volume per tube from the ratio_table
* Reject the run if **any tube would exceed 25 mL**
* Track cumulative volumes across multiple Solution-Preparation steps

---

## 5. Solution-Preparation Automation: Capabilities and Features

### ✔ 5.1 Automated Cap Management

Automatically opens or closes tube caps.

### ✔ 5.2 Precision Liquid Handling

The workstation executes the following logic:

1. Adjust cap state if needed
2. Read dosing instructions from ratio_table
3. Aspirate and dispense each reagent
4. Mix for `mixing_time_min`
5. Set final cap state according to user specification

## 8. Solution-Preparation Best Practices: Workflow Design Recommendations

### ✔ Always design a "cap-state timeline"

A simple specification like:

```
open → addition → open → ultrasonic → open → further addition → closed → centrifuge → open → …
```

prevents incorrect cap states that would cause downstream failures.

### ✔ Merge continuous liquid-addition steps into one ratio_table

If the chemistry requires multiple reagents to be added in sequence **without any intermediate processing**,
it is best to:

* Combine these additions into one ratio_table
* Use a single Solution-Preparation step

Multiple steps should only be used when an intermediate event (ultrasonic, centrifuge, oven, etc.) **must occur between additions**.

### ✔ Never manually edit ratio tables

Editing CSVs by hand risks unit mismatches, column misalignment, or accidental volume changes.
